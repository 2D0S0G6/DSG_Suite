## Configuration (Optional):

### Test Multiple Users (Advanced)

If you want to test with specific credentials:

```python
# Create a test script: test_with_users.py

from session_manager import SessionManager
from scanner import scan_url

# Setup
sm = SessionManager()
sm.register_user("student1", "student1@uni.edu", "pass123", role="student")
sm.register_user("student2", "student2@uni.edu", "pass123", role="student")
sm.register_user("teacher", "teacher@uni.edu", "pass123", role="teacher")
sm.register_user("admin", "admin@uni.edu", "admin123", role="admin")

# Login
for user in ["student1", "student2", "teacher", "admin"]:
    sm.login(user, "http://target.edu/login")

# Scan (will also use session data)
result = scan_url("http://target.edu")
```

## Troubleshooting:

### Issue: No IDOR findings reported
- **Likely:** Target doesn't have sequential IDs
- **Check:** Add some test parameters manually
- **Try:** Test specific endpoints with ID parameters

### Issue: No auth findings reported  
- **Likely:** Target requires authentication for everything
- **Check:** Manually test /admin endpoints
- **Try:** Look at 401 vs 403 status codes

### Issue: Report not generated
- **Check:** `reports/` directory exists
- **Fix:** `mkdir -p reports/`
- **Run:** Scanner again

### Issue: Slow scanning
- **Normal:** Large sites take 5-10 minutes
- **Speed up:** Can edit MAX_LINKS in scanner.py (line 23)
- **Default:** 100 links crawled, tests run on each
